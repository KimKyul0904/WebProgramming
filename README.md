## ✨ 핵심 학습 요약
수업과 과제를 진행하며 중점적으로 배운 내용들을 기록합니다.
* **CSS 셀렉터 우선순위:** 태그보다 `class`가, `class`보다 `id`가 디자인 우선순위가 높다는 것을 실습함. (`#center strong` 활용)
* **표(Table) 정렬:** `table-layout: fixed`를 사용하여 각 셀의 너비를 균등하게 고정하는 방법 학습.
* **가상 요소와 상태(Pseudo-classes):** 마우스를 올렸을 때(`:hover`) 이미지가 바뀌거나 밑줄이 사라지는(`text-decoration: none`) 동적인 UI 구현.
